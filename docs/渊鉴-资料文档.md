## 1. 项目概览

「渊鉴」是一个**单文件自包含**的账号保险库：所有代码（HTML / CSS / JS）都写在一个 `.html` 里，同一份源码可打包成三种交付形态：

| 形态 | 载体 | 数据存储 |
| --- | --- | --- |
| 网页版 | doubao-html 在线链接 | 浏览器 localStorage |
| Windows 电脑版 | Electron 封装 EXE | EXE 所在目录（AES-256-GCM 加密） |
| Android App | 手打 APK | 应用本地（AndroidSave 桥 → 下载目录） |

**唯一源码**：`账号管理工具.html`（所有三端都从这一份复制打包）。备份只需保存这一个 HTML + 设计资产 + 构建脚本/环境。

## 2. 功能规格

### 2.1 账号管理（核心）
- 记录每个账号的字段：所属网站 / App、账号名、当前与初始邮箱、密码、密保问题、生日、备注（自由文本，如「地区：xxx」）。
- 每条账号三个按钮：**编辑** / **历史密码** / **详细信息**（只读、可复制）。

### 2.2 历史密码（附带）
- 独立弹窗表格：「原密码 → 修改密码 → 修改时间」，默认星号遮罩，可显示全部。

### 2.3 密码生成器（辅助）
- 随机密码：长度直接输入、大小写/数字/符号开关。
- 记忆短语密码：中文自动转拼音、按音节打散穿插，保留词序，如「无敌」→「wu(夹杂)di」。
- 强度检测：zxcvbn（主流方法），双 CDN 回退。

### 2.4 安全与登录
- 免密直入（默认）：数据同样全程加密落盘（随机设备密钥），并非明文。
- 可选主密码保护：设备密钥再由主密码派生密钥二次包裹。
- 多层加密：AES-256-GCM（每块独立 IV＋认证标签）＋ PBKDF2 60 万次迭代；桌面端主进程再加一层整文件加密。
- 加密字段：`dataIv / data`、`dev.{salt,iter,verifierIv,verifier,wrapIv,wrapped}`。
- 自动锁定（可选）。

### 2.5 云端备份与同步
- 多方式 WebDAV 云端备份（默认坚果云，兼容其它）；二级配置页；一级显示所选方式与上次备份时间。
- 自动同步：打开比对云端/本地时间，云端新则恢复；退出自动上传。
- 手动存档：`vault-manual-YYYYMMDD-HHMMSS.json`，不覆盖自动备份。
- 本地备份：导出/导入 JSON。

### 2.6 界面
- 浅色主题（蓝色系）；桌面侧栏、手机底部标签，顺序均为「我的账号 → 密码生成器 → 云端备份 → 设置」，默认进入「我的账号」。
- 字体：MiSans（在线加载，离线回退）。

## 3. 技术架构与实现要点

### 3.1 单文件自包含：CSS/JS 内联，页内视图切换（`switchView()`），外部库走 jsDelivr 双 CDN 回退。
### 3.2 文件桥：`loadStorage()/saveStorage()` async；桌面优先 `NativeFile.load/save`，否则 localStorage；`downloadText()` 优先 `AndroidSave`。
### 3.3 同步：`vault.dav={method,url,user,pw,dir,lastSync,lastLocal,autoSync,lastManual}`；`autoSyncOpen/Exit`、`davManual*`。
### 3.4 密码生成：pinyin-pro + `PYFALLBACK` 兜底；zxcvbn 强度 0–4。
### 3.5 LOGO：内联 SVG（favicon data-URI + 三处品牌图标），矢量渲染。

## 4. 数据模型与加密

### 4.1 账号对象
```json
{"platform":"网站/App","username":"账号名","email":"当前邮箱","email_initial":"初始邮箱","password":"密码","security_question":"密保问题","birthday":"生日","note":"备注","passwordHistory":[{"old":"原密码","new":"修改密码","time":"修改时间"}]}
```

### 4.2 加密方案（多层，数据永不明文）
- 层1 设备密钥 DK（随机 256 位）：AES-256-GCM 加密保险库，每块独立 IV＋认证标签（`dataIv/data`）。
- 层2 主密码包裹：PBKDF2(主密码, 随机盐, 600000 次) 派生密钥把 DK 二次包裹（`dev.wrapIv/wrapped`），并移除本地设备密钥。
- 层3（仅 Windows）主进程整文件再一层 AES-256-GCM（密钥存 %APPDATA%）。
- 校验：`dev.verifier`；免密设备密钥存 `dev.dv`（桌面）或独立键 `vault.devkey`（网页/手机）。

### 4.3 存储位置
| 形态 | 位置 |
| --- | --- |
| 电脑版 | EXE所在目录/yuanjian-data.json（密文），密钥 %APPDATA%/渊鉴/local.key |
| 手机 App | 应用本地 |
| 网页版 | 浏览器 localStorage |
| 云端 | WebDAV 目录备份文件 |

## 6. 三端构建手册

### 6.1 通用前提
```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_HOME=/path/to/apk_build/sdk
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/build-tools/34.0.0:$ANDROID_HOME/platform-tools:$PATH"
```
> sdkmanager 需 JDK17（Java 11 报 class file 61.0）。

### 6.2 网页版
见第 7 节。

### 6.3 Windows（Electron）
```bash
cd desktop
cp <源码>/账号管理工具.html assets/index.html
cp ../design/yuanjian.ico yuanjian.ico
npx electron-packager . 渊鉴 --platform=win32 --arch=x64 --out=dist --icon=yuanjian.ico --overwrite --asar
cd dist && zip -rq ../渊鉴-win64.zip 渊鉴-win32-x64
```
> 需 wine64 + icoutils（写 exe 图标/版本）；`wrestool -l dist/渊鉴-win32-x64/渊鉴.exe` 验证。

### 6.4 Android APK（手打，不走 Gradle）
```bash
cd app
for f in res/mipmap-*/ic_launcher.png; do $ANDROID_HOME/build-tools/34.0.0/aapt2 compile -o compiled "$f"; done
mkdir -p gen
$ANDROID_HOME/build-tools/34.0.0/aapt2 link -o base.apk -I $ANDROID_HOME/platforms/android-34/android.jar --manifest AndroidManifest.xml -A assets --java gen $(ls compiled/*.flat)
mkdir -p classes
javac -source 8 -target 8 -encoding UTF-8 -classpath $ANDROID_HOME/platforms/android-34/android.jar -d classes src/com/example/accountvault/MainActivity.java gen/com/example/accountvault/R.java
mkdir -p outdex
$ANDROID_HOME/build-tools/34.0.0/d8 --release --lib $ANDROID_HOME/platforms/android-34/android.jar --output outdex $(find classes -name '*.class')
cp outdex/classes.dex classes.dex && zip -q base.apk classes.dex
$ANDROID_HOME/build-tools/34.0.0/zipalign -f 4 base.apk aligned.apk
$ANDROID_HOME/build-tools/34.0.0/apksigner sign --ks release.keystore --ks-pass pass:vault123 --ks-key-alias vault --key-pass pass:vault123 --out 渊鉴.apk aligned.apk
$ANDROID_HOME/build-tools/34.0.0/apksigner verify --print-certs 渊鉴.apk
$ANDROID_HOME/build-tools/34.0.0/aapt2 dump badging 渊鉴.apk | grep application-label
```
> 签名参数是 `--ks-key-alias`（不是 `--key-alias`）；验证应得 `application-label:'渊鉴'`。

## 7. 网页发布方法
```bash
cd /path/to/账号保险库
lark-cli apps +deploy --file-path ./账号管理工具.html --app-id app_17gu3g73n77
lark-cli apps +release-get --app-id app_17gu3g73n77 --release-id <release_id>
```
- 判断成败看返回 JSON 的 `ok`；轮询到 `status=finished` 再读 `online_url`；发布后禁止再访问链接检查。

## 10. 重写与恢复指引
- 网页版：导出 JSON 备份。

- 云端：WebDAV 自动恢复。
- 重写：以唯一源码为基，改后重打包/重发布；关键锚点：`switchView`、`loadStorage`/`saveStorage`、`NativeFile`/`AndroidSave`、`PBKDF2`/`AES`/`verifier`/`dataIv`、`autoSyncOpen`/`autoSyncExit`、`davManual`、`genRandom`/`genPhrase`/`PYFALLBACK`、`zxcvbn`。
